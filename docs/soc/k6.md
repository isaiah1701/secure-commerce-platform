# Bounded SOC traffic

Run only against the owned commerce lab:

```bash
k6 run -e BASE_URL=https://shop.platf0rm.site \
  -e SCENARIO_ID=auth-burst-20261030 \
  -e RATE=1 -e DURATION=60s soc/k6/scenarios.js
```

The script uses at most two VUs and one request per second. Set `KILL_SWITCH=true` to disable requests immediately. Every request carries `X-SOC-Scenario-ID` for correlation. Use designated test credentials only; never use real user accounts.
